# 💧 Consumo de Água

## 🎯 Objetivo

Este projeto foi desenvolvido em Python para classificar o perfil de consumo de água de imóveis e emitir alertas educativos aos moradores.

## 🏠 Tipos de imóvel

O sistema considera três tipos de imóveis:

- 🏢 Comercial
- 🏠 Casa
- 🏢 Apartamento

```bash

📊 Classificação
🏢 Imóvel comercial: tarifa comercial.
🏢 Apartamento com consumo menor que 10 m³: consumo econômico.
🏠 Casa ou apartamento com consumo de até 25 m³: consumo moderado.
⚠️ Demais situações: consumo excessivo.

🌱 Conscientização ambiental
O projeto busca incentivar o consumo responsável de água e a identificação de possíveis desperdícios ou vazamentos.
